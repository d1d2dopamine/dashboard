# Сейчас — личный дашборд

Одна задача на экране, таймер на пять минут, ритм без сгорающих стриков,
активность с GitHub и цель по вузу. Без сборки, без библиотек, без сервера.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | разметка |
| `style.css` | оформление, светлая и тёмная темы |
| `app.js` | вся логика интерфейса |
| `stats.js` | наблюдения: статистика по собственному журналу |
| `sync.js` | синхронизация между устройствами через приватный gist |
| `sw.js` | работа без интернета |
| `manifest.webmanifest`, `icon.svg`, `icon-maskable.svg` | установка на главный экран телефона |
| `worker.js`, `wrangler.jsonc` | необязательный прокси к GitHub через Cloudflare |
| `.github/workflows/data.yml` | раз в час кладёт свежий `data.json` рядом с сайтом |

## Запуск

```bash
cd dashboard
python3 -m http.server 8000
```

Открыть `http://localhost:8000`, демо-режим — `http://localhost:8000/?demo=1`.

Важно: через `file://` не будет работать оффлайн-режим и установка на телефон.
Для телефона сайт должен лежать на HTTPS-адресе — подходит GitHub Pages.

## Синхронизация без сервера

Хранилище — приватный gist в твоём аккаунте GitHub. Никаких баз, хостингов и подписок.

1. Открыть github.com/settings/tokens → **Tokens (classic)** → Generate new token.
2. Отметить только одно право: **`gist`**. Срок — можно без истечения.
3. В сайте: шестерёнка → блок «Синхронизация устройств» → вставить токен → **Подключить**.
4. На телефоне открыть тот же сайт и вставить **тот же токен**. Хранилище найдётся само.

Как ведёт себя:

- Сохраняет в localStorage мгновенно, в gist — через две с половиной секунды после последнего действия.
- Также синхронизирует раз в минуту и каждый раз, когда вкладка снова становится видимой.
- Оффлайн всё работает как обычно; как только появляется сеть — изменения уезжают сами.
- Слияние поэлементное. Добавил задачу на телефоне оффлайн, а другую на компьютере — останутся обе.
- У каждой записи есть метка времени: при конфликте побеждает более свежая версия.
- Удалённое помечается флагом, а не стирается — иначе удалённое воскресало бы с другого устройства.
- Минуты и события считаются отдельно по каждому устройству и складываются.
- Тема и текущий уровень сил остаются локальными: на телефоне может быть тёмная, на компьютере светлая.

Точка рядом со значком синхронизации в шапке: зелёная — всё уехало,
синяя мигает — идёт обмен, оранжевая — оффлайн, красная — ошибка, серая — выключена.
Нажатие на значок запускает синхронизацию вручную.

## Установка на телефон

Приложение ставить не нужно. Открыть сайт в браузере:

- **Android, Chrome** → меню → «Добавить на главный экран»
- **iPhone, Safari** → Поделиться → «На экран Домой»

После этого сайт открывается без адресной строки и работает без интернета.

## Наблюдения

Никакого ИИ. Обычная статистика по собственному журналу, всё считается в браузере.
Каждый пункт появляется только когда данных достаточно.

| Наблюдение | Как считается | Сколько нужно данных |
|---|---|---|
| Рабочие часы | гистограмма по часам, скользящее окно в 3 часа | 10 событий |
| Коэффициент искажения времени | медиана факт / оценка | 4 закрытые задачи с оценкой |
| Обычная длина захода | медиана длины сессий | 4 сессии |
| Реальные дни до этапа | календарные дни × доля активных дней за месяц | 5 активных дней |
| Застрявшие задачи | счётчик откладываний ≥ 3 | сразу |

Три правила, которые соблюдаются намеренно:

1. Никаких вероятностей вроде «ты это не сделаешь». Предсказание-приговор — прямой путь к тому, чтобы закрыть вкладку навсегда.
2. Если данных мало — показывается счётчик «сколько ещё нужно», а не выдуманный вывод.
3. Оценка времени необязательна. Ставишь — получаешь свой коэффициент, не ставишь — ничего не ломается.

Таймер записывает минуты той задаче, которая была в блоке «Сейчас» в момент запуска,
поэтому коэффициент искажения накапливается сам собой.

## Что внутри и почему именно так

1. **Блок «Сейчас»** — одна задача крупным шрифтом. Выбор из списка — самая дорогая операция.
2. **Уровень сил** — фильтр задач по тому, сколько ресурса есть прямо сейчас.
3. **Таймер на пять минут** с явным разрешением бросить.
4. **Защита от гиперфокуса** — напоминание встать после длинной цепочки работы.
5. **Быстрая запись по `N`** — внешняя рабочая память.
6. **Ритм вместо стрика** — дней из 30 и две заморозки в месяц. Ничего не сгорает.
7. **Физическое время** — полоса убывания и «примерно N выходных» вместо голого числа дней.
8. **Сделано сегодня** — доказательства, а не план.
9. **Забытое** — задачи старше недели и репозитории старше десяти дней.
10. **Новизна** — цвет и челлендж меняются каждую неделю.
11. **Автоархив** — задачи старше 30 дней уходят тихо, без чувства вины, с кнопкой вернуть.
12. **Первый шаг** у каждой задачи — физическое действие, а не абстракция.
13. **Обратная связь** — звук и всплывающая подсказка на каждое действие.
14. **Наблюдения** — статистика по себе вместо советов из интернета.

## Каскад данных GitHub

1. `./data.json` — если настроен GitHub Actions из `.github/workflows/data.yml`
2. `/api/github` — если развёрнут Cloudflare Worker
3. публичный REST API — без токена, видны последние 90 дней

Сайт полностью работает и без GitHub — просто пустые блоки активности.

## Деплой на GitHub Pages

Каждый аккаунт может иметь один сайт вида `ник.github.io` и сколько угодно
сайтов вида `ник.github.io/проект`. Портфолио остаётся на месте.

1. Новый репозиторий `dashboard`, залить туда эти файлы.
2. Settings → Pages → Deploy from a branch → `main` / `root`.
3. Через минуту сайт будет на `https://ник.github.io/dashboard`.

Репозиторий с сайтом должен быть публичным, но все твои данные лежат в приватном gist,
а токен хранится только в браузере устройства и никогда не попадает в код.

## Обновление оффлайн-кэша

После правки файлов увеличить версию в `sw.js`:

```js
const CACHE = "dashboard-v4";
```

Иначе телефон может ещё некоторое время показывать старую версию.
